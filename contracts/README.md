# Contracts

Foundry project for on-chain verification (F1.2 baseline; Phase 3 will add the registry contracts per specs/phase-1/protocol-spec.md).

## `Groth16Verifier.sol`

Generated by snarkjs from the `poseidon-baseline` circuit's proving key — not hand-written. To regenerate after a circuit change:

```sh
cd circuits/poseidon-baseline
npx --prefix .. snarkjs zkey export solidityverifier circuit_final.zkey ../../contracts/src/Groth16Verifier.sol
```

## Test

```sh
forge test -vv
```

Runs against Foundry's in-memory EVM using a real proof/public-signal fixture from `circuits/poseidon-baseline/{proof,public}.json` (input `{"in": ["1", "2"]}`). Covers F1.2: genuine proof verifies, a tampered proof and a tampered public input are both rejected.

## Deploy to a local Anvil chain

```sh
anvil --port 8545 &

forge create src/Groth16Verifier.sol:Groth16Verifier \
  --rpc-url http://127.0.0.1:8545 \
  --private-key 0xac0974bec39a17e36ba4a6b4d238ff944bacb478cbed5efcae784d7bf4f2ff80 \
  --broadcast
```

The private key above is Anvil's well-known default test account #0 — public, documented, and only ever funded on ephemeral local chains. Never reuse it anywhere real.

Then call `verifyProof` directly against the deployed contract via `cast call` to confirm on-chain verification independent of `forge test`'s in-memory EVM — see `git log` for the exact commands used in the F1.2 validation run.
